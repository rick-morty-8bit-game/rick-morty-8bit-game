Rick & Morty: 8-Bit Multiverse — сборка APK только с телефона

В ZIP добавлен GitHub Actions workflow для облачной сборки APK. Сам APK ещё не включён — его создаст GitHub Actions после загрузки проекта в репозиторий.

Порядок действий на Android:
1. Скачай и распакуй RickMortyAndroid_project.zip (можно через приложение Files или файловый менеджер).
2. В браузере открой https://github.com и войди/создай аккаунт.
3. Создай новый репозиторий (например RickMortyAndroid). Для простоты можно сделать Public; если выбираешь Private, убедись, что GitHub Actions разрешены.
4. В интерфейсе репозитория выбери Add file → Upload files. Загрузи содержимое папки проекта, включая папку .github/workflows/build-apk.yml. В мобильном интерфейсе загрузка папок может быть неудобной; при необходимости включи в браузере «Версия для ПК».
5. Нажми Commit changes.
6. Открой вкладку Actions → Build Android APK. Если workflow не запустился сам, нажми Run workflow.
7. Дождись зелёной галочки у сборки. Открой завершённый запуск и скачай artifact `RickMortyMultiverse-debug-apk`.
8. Распакуй artifact ZIP, найди `app-debug.apk`, открой его и подтверди установку. Если Android попросит, разреши браузеру/файловому менеджеру устанавливать неизвестные приложения.

Требования:
- GitHub аккаунт и доступ к GitHub Actions.
- Это debug APK для личного тестирования, не готовая публикационная сборка.
- Не передавай никому пароль GitHub или коды подтверждения.
- Персонажи и бренд Rick and Morty принадлежат их правообладателям; публичное распространение может требовать разрешения.
